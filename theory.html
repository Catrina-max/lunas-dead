1.1 / PREMISE

Luna's Dead begins from a simple design proposition: the player should not confuse a representation with the thing represented.

PROPOSITION 01The experienced world is a rendering, not a guaranteed disclosure of the underlying state.

This does not require the game to deny reality. It requires the game to distinguish between what exists, what an observer can perceive, and what an observer concludes.

1.2 / HOFFMAN

Perception as interface

Donald Hoffman's Interface Theory of Perception is used here as a design provocation. Its most productive contribution to the game is not a metaphysical conclusion but a computational distinction:

state ≠ rendering

If observers do not receive transparent access to the underlying state, then one historical event can support multiple experienced worlds: an institutional reconstruction, a memory, a physical trace, a ghost's account, or Luna's own changing perception.

DESIGN CONSEQUENCEA ghost is not automatically a truth oracle. Luna does not unlock “truth vision.”

The player advances by comparing interfaces.

1.3 / OLEA

Value through context and deviation

Óscar Olea's axiological and information-oriented approaches to criticism provide a complementary design problem: an object does not become meaningful in isolation. Its significance depends on a field of expectations, relations, history, style, and deviation.

For game design, this suggests that the player must first learn the grammar of a place before an anomaly can become legible.

ENVIRONMENTAL GRAMMAR

1980s motorcycle garage → tools, oil, analog media, repair parts, leather, club photographs.

DEVIATION

A material or object inconsistent with that grammar.

INTERPRETIVE EFFECT

Not “the anomaly is true,” but “the current model is incomplete.”

1.4 / SYNTHESIS
Hoffman gives the project an interface problem. Olea gives it an anomaly problem.

The resulting game loop is epistemic rather than merely collectible: perceive, contextualize, detect deviation, test evidence, form a provisional model, then perceive again.

PROPOSITION 02Truth becomes approachable through relations among incomplete representations, not through a single privileged reveal.
