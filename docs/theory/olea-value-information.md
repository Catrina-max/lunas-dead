# Óscar Olea: Value, Context, and Information

## Design Use

Luna's Dead draws inspiration from Mexican professor Óscar Olea's efforts to create systematic frameworks for artistic criticism and value judgment.

The project is especially interested in the relationship among:

- context;
- expectation;
- difference;
- information;
- originality;
- interpretation;
- value.

The game does not attempt to reproduce Olea's full model literally.

Instead, it translates a critical idea into environmental design:

> Before an anomaly can mean something, the player needs to learn what the environment normally expects.

## Environmental Grammar

A room establishes a grammar.

For example:

```text
1980s motorcycle garage
├── tools
├── oil
├── repair parts
├── records / tapes
├── club photographs
├── used furniture
└── motorcycle equipment
```

Then the player finds:

```text
modern polymer cable
```

The object matters because it violates the system.

## Information

A useful conceptual heuristic is:

```text
I(x) = -log2 P(x)
```

An observation that is very likely under the current model carries little surprise.

An unlikely observation may force the player to revise the model.

But surprise is not truth.

The object might be:

- planted;
- later contamination;
- supernatural overlay;
- mistaken identification;
- evidence of a different time layer.

Critical judgment therefore remains relational rather than automatic.
