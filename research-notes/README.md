# Research Notes

This directory is intended for public notes that inform the project without exposing unreleased canon.

Possible subjects:

- perception and interface theory;
- probability and uncertainty;
- Shannon information;
- Markov processes;
- graph theory;
- aesthetic criticism;
- Mexican art theory;
- Día de Muertos visual culture;
- memory studies;
- evidence and legal reasoning;
- archival theory;
- game narrative;
- environmental storytelling;
- fashion as worldbuilding;
- immersive performance.

Research notes should distinguish clearly among:

- source description;
- project interpretation;
- speculative design idea;
- established game decision.
